# يارا | Yara - Romantic Elevator 🌙✨

مشهد أنمي رومانسي ساحر وتفاعلي بالكود (HTML5 / TailwindCSS / Web Audio API / Canvas).

## عن المشروع
- **المشهد:** فتاة محجبة وشاب يرتدي نظارة يقفان داخل مصعد زجاجي بانورامي يهبط بهما وسط أضواء مدينة طوكيو الساحرة ليلاً، وكل منهما ينظر في اتجاه مختلف خجلاً وارتباكاً في صمت المصعد.
- **الهبوط:** يبدأ عداد المصعد الرقمي بالنزول من الدور 16 نحو الأسفل بصمت وبسلاسة مع حركة بوكيه المدينة الصاعدة للأعلى.
- **الموسيقى:** معزوفة بيانو رومانسية هادئة (River Flows In You - Style) مبرمجة مباشرة عبر تقنية Web Audio API دون الحاجة لأي ملفات صوتية خارجية.
- **التوافق:** تصميم متجاوب بالكامل 100% يدعم شاشات الكمبيوتر وشاشات الهواتف الذكية (Portrait 9:16 و Landscape 16:9).

## تشغيل المشروع
فقط افتح ملف index.html في أي متصفح ويب حديث.
